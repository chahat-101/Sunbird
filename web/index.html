Sunbird

Send one file. It is encrypted in this browser before it is uploaded. The server stores bytes it cannot read, and deletes them after the time or number of downloads you choose.

Want someone to send you a file instead? Request a file. You get a link with no key in it, which is safe to post anywhere.

Fingerprint

Ask the person who made the request what fingerprint their page shows, by some other way than the one the link came by. If it is not the same, someone changed the link: do not upload.

Who can open it

Public link: anyone who has the link can open this file. There is no passphrase or other second factor.

Passphrase-protected: the file opens only with the link and the passphrase together. Send the passphrase separately from the link.

Length is what makes a passphrase hard to guess: a few ordinary words beat one short word full of symbols, and are easier to say aloud. It is used exactly as typed, spaces included. 0 characters

Limits

Both limits are sealed into the file and cannot be changed after upload. The server stops serving the file and deletes it when the first one is reached.

Upload token

This is a shared server. Your upload token identifies you to the server's admin: every file you upload is recorded as yours, so the admin can see who uploaded a file and remove it. Anyone with your token uploads as you.

Sign in with Google

No token? If this server allows it, sign in with Google to get one. You leave this page, and come back to a page showing your new token. That tells Google you used this server. The server keeps only a one-way hash of an opaque Google ID, not your email. A token from the admin involves no third party.

Sunbird

Request a file.

Make a link that someone can use to send you a file. The link holds no secret, so it is safe to post anywhere. Whatever is sent to it opens only in this browser.

Fingerprint

The sender sees a fingerprint when they open the link. Before they upload, check with them that it is the same as this one. They then send you a link back: open it in this browser.

Waiting requests

None in this browser.

    In a private window, the key is lost when the window closes, and nothing sent to the request can be opened after that.

    Each request keeps a key in this browser until a file sent to it has been opened, or for 7 days. Anyone who can use this browser profile can use that key until then. One request takes one file, and at most 20 can wait at once.
